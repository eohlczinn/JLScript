# Sobre

A **JLScript** é uma linguagem de programação open source desenvolvida para tornar a programação mais simples, intuitiva e acessível.

Seu objetivo é oferecer uma sintaxe limpa, comandos em português e ferramentas modernas para desenvolvimento de aplicações.

A linguagem é desenvolvida em **C++** e acompanha uma extensão oficial para **Visual Studio Code**, além de um gerenciador de bibliotecas próprio.

---

# Exemplo

```jls
import #api como #ap

va resposta =
    #ap.get(
        "https://api.exemplo.com"
    )

mostrar(resposta.body)
```

# Instalação

```bash
jls install
```

ou baixe a versão mais recente na página de Releases.

---

# Primeiro programa

```jls
mostrar("Olá, Mundo!")
```

Execute:

```bash
jls run ola.jls
```
